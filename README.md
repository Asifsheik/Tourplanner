# 🌍 Travel Website Homepage – Week 2 Project

## 📌 Project Description

This project involves designing and developing a modern, responsive travel website homepage using **HTML and CSS**. The website features an original travel brand with an attractive layout that helps users explore popular destinations, discover hotels, find top-rated restaurants, and search for travel experiences.

The main goal of this project is to create a visually appealing and user-friendly interface while practicing essential web development skills, including page structure, styling, responsive design, and layout techniques.

## 🎯 Objectives

* Build a structured webpage using HTML.
* Design a custom header with a logo, search bar, and navigation menu.
* Create an interactive navigation menu with CSS hover effects.
* Display featured destinations, popular hotels, and top-rated restaurants using cards.
* Design a search section with destination input and filters.
* Use CSS Grid and Flexbox to create organized layouts.
* Implement responsive design using CSS media queries.
* Develop an original travel website design without copying existing travel platforms.

## ✨ Features

* **Custom Branding:** An original travel website design with a unique identity.
* **Navigation Bar:** Easy navigation to Hotels, Flights, Restaurants, and other travel sections.
* **Destination Search:** A search interface for exploring cities and travel destinations.
* **Featured Destinations:** Attractive destination cards highlighting popular places.
* **Hotel and Restaurant Listings:** Cards featuring images, ratings, titles, and short descriptions.
* **Modern UI Design:** Clean styling, attractive colors, and a visually appealing layout.
* **Hover Effects:** CSS transitions and interactive effects for navigation links and cards.
* **Responsive Layout:** A mobile-friendly design that adapts to desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

* **HTML5** – For structuring the webpage and organizing content.
* **CSS3** – For styling, layouts, hover effects, and responsive design.
* **CSS Flexbox & Grid** – For creating flexible and organized page layouts.
* **Media Queries** – For adapting the design to different screen sizes.

## 📱 Responsive Design

The website is designed to provide a consistent browsing experience across desktop computers, tablets, and mobile devices. CSS media queries help adjust the layout, navigation, and content cards according to different screen sizes.

## 🎓 Learning Outcomes

Through this project, I practiced:

* Creating semantic HTML structures.
* Designing modern website layouts using CSS.
* Working with Flexbox and CSS Grid.
* Implementing hover effects and styling interactive elements.
* Building responsive web pages using media queries.
* Developing an original website design and improving frontend development skills.

## 🚀 Project Goal

The goal of this project is to strengthen my frontend development fundamentals by building a responsive travel website homepage with a custom design, organized content sections, and a user-friendly interface.
